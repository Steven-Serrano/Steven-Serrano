## Sobre mí

Soy Jhojan Steven Serrano Patiño, desarrollador web junior y aprendiz del SENA en el programa de Análisis y Desarrollo de Software (ADSO), en Colombia.

Me interesa el desarrollo web, la creación de aplicaciones y la conexión entre interfaces, servidores y bases de datos. Me gusta aprender nuevas tecnologías mediante proyectos prácticos y mejorar progresivamente la calidad de mi código.

Actualmente estoy fortaleciendo mis conocimientos para crecer como desarrollador Full Stack.

## Mi forma de trabajar

text
01. Comprender el problema.
02. Planificar una solución.
03. Escribir código claro y organizado.
04. Probar las funcionalidades.
05. Corregir errores y documentar.
06. Aprender de cada proyecto.


No todo sale a la primera. A veces el error está en una línea de código; otras veces, en las últimas tres horas de código que nadie quiere borrar.
